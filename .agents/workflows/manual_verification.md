---
description: Guidelines for manual verification only
---
1. Skip the "Automated Tests" section in implementation plans when this workflow is active.
2. Rely exclusively on manual visual and functional checks.
3. Provide the user with the exact URL (e.g., http://localhost:5173/) and a clear checklist of what to verify.
4. Ask the user for explicit confirmation that the UI looks and behaves as expected.
5. Only mark a task as fully verified after the user provides positive feedback or you have personally verified the UI via the browser tool (taking screenshots as proof).
