---
description: Guidelines for creating implementation plans
---
1. For any task that isn't a minor one-off fix, first perform research to understand the project structure.
2. Create an implementation_plan.md artifact with:
   - A brief summary of the goals.
   - The proposed changes grouped by components.
   - Any open questions for the user.
   - A verification plan.
3. Set `request_feedback = true` in the artifact metadata.
4. Stop and wait for the user's explicit approval before proceeding to any source code modifications or execution.
